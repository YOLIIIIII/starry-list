# 星轨日历 Starry List V1.0 用户手册

星轨日历是一款保存在电脑本地的日历待办工具。无需账号，日常使用无需联网。你可以用「统筹总览」安排不同日期，再用「专注编辑」写下具体步骤。

本文按 V1.0 实际界面、任务编辑器、设置及安装器配置编写。界面默认使用简体中文。安装器中的应用名称为 **Starry List**，应用窗口内显示「星轨日历」。

2026-10-16 更新：以下快速新增、任务菜单和字号说明对应第二轮 UX 体验版；旧安装包可能没有这些交互。

## 首次使用五分钟快速上手

1. 安装默认透明版，从 Windows 开始菜单搜索 **Starry List** 并打开。
2. 在「统筹总览」的月历中点击今天的日期数字。右侧「接下来七天」从这一天开始；窄窗口中它位于月历下方。
3. 点击今天日期行右侧的小加号，在出现的输入框填写标题，按 **Enter**。新增任务只需要标题，成功后输入框自动收起。
4. 点击任务标题，进入「专注编辑」阅读详情。点击「编辑」，在抽屉的「详细计划」写下步骤，选择「重要」或「非常重要」，再点击底部「保存并收起」。
5. 完成后点击任务左侧的空心圆。最后点右上角齿轮，向下找到「数据备份」，用「导出 JSON」保存第一份备份。

初次启动进入「统筹总览」；以后启动会记住上次的工作模式，日期从当天开始。任务与设置由两个模式共享，无需重复录入。

## 1. 安装、选择版本与启动

### 安装 Windows 版本

1. 获取项目提供的 Windows x64 `-setup.exe` 安装包。正式发布后，在仓库 GitHub 的 **Releases → 对应版本 → Assets** 中下载；尚未发布时，可使用维护者提供的本地构建产物。
2. 双击安装包，选择安装器语言，按提示选择安装位置和开始菜单快捷方式位置。安装器面向当前 Windows 用户安装。
3. 安装器完成页提供「创建桌面快捷方式」选项，按需要选择。
4. 打开 Windows 开始菜单，搜索 **Starry List**，点击应用快捷方式；也可以使用安装时创建的桌面快捷方式。

目标系统为 Windows 10/11 x64；目前实际验证环境为 Windows 11，其他设备的验证范围见 [验证记录](VALIDATION.md)。应用需要 Microsoft Edge WebView2 Runtime。安装包内置运行时引导程序，系统缺失运行时时，首次安装可能需要网络；日常管理任务不需要网络。

当前安装包未配置代码签名，Windows 可能显示「未知发布者」或 SmartScreen 提示。源码中的版权和安装包发布者显示现已统一为 `yoli`；现有旧安装包需要重新构建才会包含更新，见 [验证记录](VALIDATION.md)。该署名不是已验证的签名证书身份。请核对安装包来源及维护者提供的 SHA256。

### 安装第二轮 UX 体验版

本轮默认透明版文件名为 `Starry-List_1.0.0_x64-ux2-preview-20261016-setup.exe`，配套校验文件为 `UX2-PREVIEW-20261016-SHA256SUMS.txt`，均在维护者本地 `artifacts/` 目录，不随源码上传 GitHub。它仍使用 1.0.0 和相同应用标识，会更新同一个应用，不是并行安装的第二套软件。

先在旧版设置中「导出 JSON」备份重要任务，再正常关闭旧版。运行新安装器，沿用原安装目录；如果检测到同版本，选择「添加/重新安装组件」继续覆盖，不要选择卸载。该选项已按实际生成的 NSIS 脚本核对，但本轮没有执行安装器验证。无需为了更新而手动卸载或删除数据目录。如果提示应用仍在运行，取消后正常退出旧版再重试。提示不明确时保留备份并取消，不要勾选「删除应用程序数据」来解决。安装后从开始菜单重新启动，检查任务和详情是否保留。

### 透明版和不透明回退版怎么选

| 版本                                | 适合的情况                                   | 背景设置                                           |
| ----------------------------------- | -------------------------------------------- | -------------------------------------------------- |
| 默认透明版：文件名不含 `opaque`     | 希望窗口融入桌面壁纸，优先选择此版           | 可调整背景不透明度；也可打开「实色背景回退」       |
| 原生不透明回退版：文件名含 `opaque` | 透明版出现渲染异常，或希望使用原生不透明窗口 | 窗口不会透视桌面，透明度滑块不可操作，并有明确说明 |

透明版显示异常时，先尝试「设置 → 实色背景回退」。如果窗口本身无法正常呈现，再使用原生不透明回退安装包。两版使用相同应用名称和数据目录；切换前先导出备份并退出应用。如需卸载，注意不要勾选删除应用数据。

## 2. 认识界面与统筹总览

窗口最上方左侧是星球图标和名称，中间的空白标题区可以拖动。右上角依次是图钉、齿轮、最小化和关闭按钮。标题区下方有「统筹总览」「专注编辑」切换按钮。

宽窗口中，统筹总览左侧是月历，右侧是「接下来七天」。窗口变窄后两块区域上下排列；更窄时，月历预览会减少文字，保留任务数量和重要任务标记。七天日程可以独立向下滚动，不需要把七天全部塞进一屏。

参考 [统筹总览截图](screenshots/overview.png) 和 [紧凑窗口截图](screenshots/compact.png)。截图使用示例任务，不代表你的数据库中预装了任务。

### 查看月历

- 月历从周一开始；月份标题右侧的左右箭头切换上个月、下个月，中间「今天」返回当天。
- **点击日期数字**选择日期。当天使用实心紫色日期标识，选中日期使用边框和底色，两者含义不同。
- 日期格中的任务预览优先显示未完成任务，再优先显示较重要的任务；预览数量随格子空间调整。`+N` 表示还有 N 项未显示的任务。
- 将鼠标放在任务预览上可查看完整标题；点击预览会直接进入该任务的专注编辑。
- 仅切换月份是在浏览月历，**不会自动改变七天日程的起点**。点击具体日期后，七天日程才从该日期开始。

### 查看连续七天的任务

「接下来七天」标题旁显示日期范围。每个日期分组显示日期、星期或「今天」，以及尚未完成的「N 项待办」；有任务时，分组下方还有「已完成数 / 总数」进度。

该区域标题右侧有三个图标按钮：左箭头「上一周」、中间日历图标「回到今天」、右箭头「下一周」。箭头将当前起点前后移动七天，可跨月、跨年。点击某个分组的日期标题，会将它选为新的起点。

空日期默认只有紧凑日期行和「0 项」，不显示输入占位符。每个日期右侧的小加号可打开该日期的新增输入栏；标题区域的「新增」按钮为当前选中日期打开输入栏。整段七天都没有任务时，只显示一次整体提示。

## 3. 在指定日期新增待办

**总览中新增：**先看清日期分组，点击日期行右侧加号，在出现的「添加一件小事…」中输入标题，按 **Enter**；也可点击旁边出现的「添加」。成功后输入框收起并显示真实任务，焦点回到该日期的加号。任务自动归属该分组日期，而不是一律归到今天。

**专注中新增：**确认主区域顶部日期，在「当日清单」的列表最下方找到同样的输入栏。任务较多时，需要在列表里向下滚动。

新增时无需选择分类、优先级或填写详情。保存成功后输入栏清空，任务出现在清单和月历中。若添加失败，输入文字会保留，并显示错误，请处理后重试。

七天日程同一时间只展开一个新增区。输入框为空或只有空白时，点击外部、再次点该日期加号、按 **Esc** 或点输入旁的关闭按钮都会收起；直接点其他日期加号会切换到那个日期，不创建空任务。

已经输入文字时，点击外部会保留输入。按 Esc、点关闭按钮、换日期、换七天范围、换模式或打开其他任务时，会在新增栏下方出现轻量提示：

- **继续填写**：保留草稿，取消刚才的切换。
- **放弃草稿**：明确丢弃未添加文字，再完成刚才的操作。
- **添加并继续**：先保存到原输入栏所属日期，成功后再完成切换；保存失败保持原位置和文字，可重试。

专注清单也使用相同的草稿保护；空白取消后保留常驻新增栏，七天日程则收起。新增输入、占位符和真实任务标题统一为 15px；这是局部调整，目前设置中没有全局字号档位。中文输入法组合期间 Enter / Esc 不会误添加或取消。草稿仍不是已保存任务，强制结束进程无法保证恢复，请主动提交重要内容。参考 [快速新增草稿提示](screenshots/quick-add.png)。

## 4. 完成、取消完成与进度

在七天日程或专注清单中，点击任务左侧的**空心圆**即可标记完成。完成后显示勾号，标题变浅并带删除线，任务排列到未完成任务之后。

再次点击勾号可以取消完成。星星或王冠的优先级仍保留，不会因为完成而被清除。两个视图的状态与任务数量会同步。

七天分组中的「N 项待办」只统计未完成任务；进度的分母包含全部任务。专注模式「当日清单」旁的数字也是当天全部任务数。

## 5. 专注编辑、详情和保存

点击顶部「专注编辑」进入当前选中日期的每日清单；也可以从总览直接点击任务标题或月历任务预览。

顶部日期右侧有前一天、后一天箭头及「今天」按钮。下方七天日期条以当前选中日期为中心，显示前三天、当天和后三天；点击某一天切换清单，日期下的小圆点表示这一天有任务。

任务默认是紧凑的一行。点击**任务标题**，先展开只读详情，展示完整标题、日期、重要程度、可选分类和详细计划，不会直接出现输入表单。长计划保留换行，在有高度上限的区域内滚动阅读；没有计划时保持紧凑。再次点击标题或收起按钮即可收起阅读卡片。

点击只读详情右上方的「编辑」，才会打开独立编辑抽屉。宽窗口中抽屉位于右侧，宽约 520px；窄窗口中占满可用宽度。它仍在同一个应用窗口内。抽屉的标题和底部操作固定，中间表单可以独立滚动。

参考 [专注编辑截图](screenshots/focus.png)。

### 撰写长文本

在编辑抽屉的「详细计划」多行文本框中写中文段落、换行、编号或列表。例如：

```text
调研范围：
1. 产品 A 的功能设计
2. 产品 B 的使用体验

下一步：
整理对比表，周五完成初稿。
```

这是纯文本编辑器，编号和列表作为文字保存，没有富文本工具栏。在文本框内按 Enter 是换行。文本框初始高度约 156px，随文字增高，最高约 340px；更多内容在文本框内滚动。其他字段可在表单中滚动查看，底部保存按钮始终可见。参考 [编辑抽屉](screenshots/editor.png) 与 [窄窗口编辑](screenshots/editor-compact.png)。

### 保存与取消编辑

- 点击抽屉底部「保存并收起」，或在编辑框内按 **Ctrl + Enter**。应用先校验并等待写入成功，再关闭抽屉、收起阅读卡片，回到紧凑清单并提示「修改已保存」。重新点击标题即可阅读已保存内容。
- 修改后显示「未保存 · 切换时自动保存」，此时仍是草稿。原有任务、日期、模式切换及正常退出前的保存保护继续生效；保存失败会阻止切换。抽屉打开时，请先保存或取消，再操作底层列表。
- 保存失败会保留抽屉和输入，并提示「保存失败，你的输入仍保留在这里。」；解决问题后可重试，不会把失败当作成功。
- 点击「取消」、右上角关闭按钮，或按 **Esc** 退出编辑。没有修改时直接关闭；有未保存修改时，出现「保留这次修改？」确认框，可选择「继续编辑」「放弃修改」或「保存并收起」。只有明确选择「放弃修改」才会丢弃本次草稿，不会覆盖原任务。

重要长文本建议主动点「保存并收起」并确认成功提示。强制结束进程、断电时，尚未保存的草稿不能保证保留。窗口底部「本地保存 · 安心离线」不是每个编辑框都已提交的提示，请同时查看抽屉的保存状态。

## 6. 重要程度、分类与日历简称

这些入口都在**点击「编辑」后打开的抽屉中**，不在快速新增栏或只读详情中。选择后点击「保存并收起」生效。

### 星星与王冠

找到「重要程度」，选择一个胶囊按钮后保存：

| 按钮     | 清单与月历中的标识 |
| -------- | ------------------ |
| 普通     | 没有特殊图标       |
| 重要     | 黄色星星           |
| 非常重要 | 金黄色王冠         |

列表里的星星或王冠是状态标识；修改时请点击编辑抽屉内的选项。重要程度会影响月历预览的优先顺序，日清单仍按手动顺序及完成状态排列。

### 分类

「分类」位于重要程度下方。可选择「工作」「生活」「调研」「开发」「会议」「学习」，每条任务最多一个。选择「不选择」移除分类，然后保存。

分类可选，不选不会影响新增或完成。分类显示在七天日程和专注清单中；V1.0 没有分类增删改管理界面。

### 日历简称

分类下方有折叠的「更多选项」。点击展开，在「日历简称」中填写简短名称，例如将「完成 AI 调研报告」设为「AI 调研」，然后保存。

简称只用于月历预览，不改变完整标题或详情。不填写简称时，月历显示原标题，并用省略号适应空间；鼠标悬停仍能看到完整标题。清空简称并保存即可恢复原标题预览。

## 7. 改变任务日期、排序与删除

### 改变日期

展开任务的只读详情，点击「编辑」，在「任务日期」中选择新日期，再「保存并收起」。任务会移动到新日期，可能从当前清单中消失。到月历选择新日期，或在专注模式切换到新日期，即可继续查看。

### 手动排序

排序入口只在**专注编辑的任务行最右侧**，是小的上箭头和下箭头。每次点击将任务上移或下移一位，顺序即时保存，无需再打开编辑抽屉保存。

只能在同一天、同完成状态的任务之间排序：未完成任务始终在已完成任务之前，边界处的箭头不可点击。月历预览另有未完成、优先级优先的规则，所以月历顺序可能与每日清单不同。

### 删除与撤销

统筹总览的七天日程和专注清单中，每条真实任务最右侧都有 **「···」**（任务操作）。点击后选择「编辑任务」或「删除任务」，已完成任务也能使用。总览的编辑入口会自动切换到对应日期的专注模式并打开原有抽屉；点击任务标题仍然是先阅读详情。参考 [任务操作菜单](screenshots/task-menu.png)。

选择「删除任务」后，在确认框中核对标题，点「保留」取消，点「删除任务」确认。写入成功后才移除任务；失败时任务和确认框保留，并显示错误，可处理后重试。删除与撤销会同步日历预览、清单和统计，不会删除同一天的其他任务。

原入口仍保留：从只读详情点击「编辑」，在抽屉中部表单向下滚动，找到「更多选项」下面的「删除任务」。两种入口使用相同确认与撤销流程。

键盘操作：Tab 聚焦「任务操作」按钮，Enter / Space 打开；上下箭头或 Home / End 选择菜单项，Enter 执行；Esc 关闭并返回按钮，Tab 离开菜单。菜单跟随滚动重新定位，靠近窗口下边缘时向上展开。

删除后，窗口底部出现「任务已删除」通知，可点击「撤销」恢复该任务。此入口不属于长期回收站；关闭通知、退出应用或进行下一次删除等操作后，不应依赖它恢复更早删除的任务。重要任务请保留备份。

## 8. 节假日、补班与个人标记

月历内置 2026 年中国大陆官方安排，无需联网获取：

| 标记 | 含义                                   |
| ---- | -------------------------------------- |
| 休   | 官方假期，例如 2026 年 10 月 1–7 日    |
| 班   | 官方调休上班，例如 2026 年 10 月 10 日 |
| 歇   | 你设置的个人休息                       |
| 加   | 你设置的个人加班                       |

官方假期和补班会优先于普通周末底色；例如补班的星期六不会被当成普通休息周末。鼠标悬停「休」可查看假期名称，悬停「班」可查看官方补班说明。

在右上角齿轮「设置」中，可以切换「官方节假日」和「周末底色」。未录入官方安排的年份会显示提示，不会猜测调休日期。

### 标记个人休息或加班

进入「统筹总览」，在月历中选择日期。**月历下方**有「某月某日 · 个人标记」一行，通过右侧下拉框选择「个人休息」或「个人加班」；选择「无」清除个人标记。选择后即时保存。

个人标记不会改写官方安排；同一天可以同时显示官方「休」和个人「加」。V1.0 界面没有个人标记备注编辑入口。

## 9. 拖动、缩放、最小化与置顶

- **拖动：**按住顶部左侧品牌名称区域或中间空白标题区拖动。任务行、编辑框和右上角按钮不是拖动区域。
- **缩放：**拖动窗口边缘或角落，也可以按住右下角的小点阵拖动。最小窗口为约 380 × 480 逻辑像素；较小窗口会调整布局。
- **最小化：**点击右上角减号，窗口进入 Windows 任务栏；点击任务栏图标恢复。
- **置顶：**点击右上角图钉，或打开齿轮「设置」切换「始终置顶」。再次操作取消；默认关闭，选择会保存。
- **恢复：**正常退出后再启动，会恢复窗口尺寸、位置和工作模式。显示器变更时，应用会尝试把窗口调整回可见区域；不同多显示器环境仍需实际验证。

V1.0 没有系统托盘功能。右上角关闭按钮是退出应用，不是隐藏到托盘。

## 10. 背景透明度与其他设置

点击右上角**齿轮**打开「让星轨更适合你」。设置较长时在面板内向下滚动，底部有数据备份和版本说明；没有独立的「关于」菜单按钮。参考 [设置截图](screenshots/settings.png)。

默认透明版的「背景不透明度」滑块范围为 **40%–100%**，初始约 **85%**。数值越低，桌面越容易透过背景；100% 表示完全不透明。拖动时实时预览，松开或使用键盘调整后保存；文字、图标及输入区域保持清晰，不随整个窗口一起变淡。

开启「实色背景回退」后，背景完全不透明，滑块不可操作；关闭它可恢复透明度调整。原生不透明版的滑块始终不可操作，即使关闭此开关也不能透视桌面。

「柔和动画」「官方节假日」「周末底色」「始终置顶」等开关即时保存。系统要求减少动画时，界面也会减少动画。

## 11. 导出与导入 JSON 备份

### 导出

1. 点击右上角齿轮。打开设置前，应用会先尝试保存正在编辑的任务详情。
2. 在面板内向下找到「数据备份」，点击「导出 JSON」。
3. 在系统保存对话框选择位置，建议保留带日期的文件名，例如 `Starry-List-2026-10-14.json`。
4. 看到「备份已导出」后确认文件已保存。取消文件对话框不会导出。

备份包含任务、详情、分类、个人日期标记和应用设置，不包含窗口位置与尺寸，也不包含只读官方节假日数据。JSON 未加密，请妥善保管；应用没有自动云备份。

### 默认合并导入

1. 在「设置 → 数据备份」点击「导入 JSON」，选择 Starry List 导出的 JSON 文件。
2. 文件通过校验后出现「确认导入备份」，显示任务、分类和个人标记数量。
3. 保持「覆盖现有全部数据与设置」**未勾选**，点击「合并导入」。
4. 看到「备份已完整导入」后查看结果；不想导入时点击「取消」。

合并会保留现有任务和设置；同一天的个人标记保留现有值。相同任务 ID 会生成新 ID，**不会按相同标题去重**，因此重复导入同一备份可能产生重复任务。分类 ID 冲突且名称或颜色不同，会作为另一个分类保留。已有任务不会被备份悄悄覆盖。

### 完整覆盖恢复

如果希望整库恢复为备份中的内容，请先导出当前数据。在确认框勾选「覆盖现有全部数据与设置」，按提示输入 **覆盖**，然后点击「确认覆盖」。

覆盖会替换当前任务、分类、个人日期标记和设置；它不是简单追加。窗口几何状态不随 JSON 恢复。导入在事务中完成，失败时不会留下部分写入。错误版本、无效结构或超过 32 MB 的文件会被拒绝并显示错误。

## 12. 本地数据保存在哪里

正常 Windows 安装版的 SQLite 数据库位于：

```text
%APPDATA%\app.starrylist.desktop\starry-list.db
```

例如：`C:\Users\你的用户名\AppData\Roaming\app.starrylist.desktop\starry-list.db`。打开 Windows 文件资源管理器，在地址栏输入 `%APPDATA%\app.starrylist.desktop` 并回车即可进入。

任务、分类、个人标记和应用设置都在数据库内。窗口状态另由窗口状态插件保存；不是 JSON 导出内容。透明版和不透明版共用同一数据目录。

应用运行期间可能还有 `starry-list.db-wal` 和 `starry-list.db-shm` 文件，它们属于 SQLite 正常工作文件。不要在应用运行时删除它们，也不要只复制主数据库作为完整备份。一般用户优先使用应用内的「导出 JSON」；需要手动复制数据库时，先正常退出应用，再复制完整数据目录。

数据没有上传到服务器，也没有本地加密。不同 Windows 用户通常拥有各自的数据目录。重新安装程序不等于已经恢复数据，重要内容请定期导出。

## 13. 退出、卸载与重新安装

### 退出

点击右上角 **×** 关闭应用。正常关闭会先保存展开详情中的修改，并等待已有数据库写入完成；保存失败时会显示错误，不会直接丢弃详情并退出。尚未提交的快速新增标题需要先按 Enter 添加。

最小化只把窗口放到任务栏，不会退出应用，也不会隐藏到系统托盘。

### 卸载

1. 先在应用内导出 JSON 备份，再正常退出。
2. 在 Windows 设置的已安装应用列表中找到 **Starry List**，选择卸载；Windows 10 中通常位于「应用和功能」。
3. NSIS 卸载确认页有 **「删除应用程序数据」** 复选框。希望保留本地任务时，不要勾选；勾选会删除应用数据目录，包括数据库和设置。

如果需要彻底清理，也应先确认备份可用再选择删除数据。本项目尚未在全新设备上完成安装、升级、卸载回归，说明依据当前生成的 NSIS 安装器流程。

### 重新安装

重新运行可信来源的安装包，之后从开始菜单打开。数据目录仍存在时，应用会读取其中的任务；目录已经被删除时，需要用先前的 JSON 备份导入恢复。若要完整恢复到备份状态，使用明确确认后的覆盖导入；如果只是追加任务，使用合并导入。

## 14. 常见问题

| 问题                                 | 可以怎么做                                                                                                   |
| ------------------------------------ | ------------------------------------------------------------------------------------------------------------ |
| 开始菜单找不到应用                   | 搜索英文 **Starry List**，检查安装时选择的快捷方式位置，或使用桌面快捷方式；先确认安装确实完成               |
| 打开网页后提示需要桌面应用           | 请从开始菜单启动安装版；单独的浏览器预览不连接本地 SQLite                                                    |
| 七天日程没有跟着翻月份改变           | 翻月只是浏览；点击具体日期数字后才改变起点                                                                   |
| 明明有任务，月历却只显示一条或一个点 | 这是空间自适应预览；查看 `+N`，选中该日期并在日程或专注清单查看全部任务                                      |
| 找不到新增输入栏                     | 点击对应日期右侧加号展开；专注模式的输入栏在列表最底部                                                       |
| 找不到星星、王冠、分类或简称入口     | 点击任务标题查看详情，再点「编辑」；简称在抽屉的「更多选项」内；日历上的星星本身不是设置按钮                 |
| 找不到上下排序箭头                   | 切换「专注编辑」，看任务行最右侧；处于同完成状态分组边界时箭头禁用                                           |
| 保存改日期后任务不见了               | 到新日期查看；还要检查是否被标记完成并排到了清单后面                                                         |
| 长文本还显示未保存                   | 点击「保存并收起」或 Ctrl + Enter，查看错误和保存状态；不要直接强制结束程序                                  |
| 提示保存失败或启动时无法读取数据库   | 检查磁盘空间和数据目录写入权限。保留输入与原数据；不要为了消除提示删除数据库。启动失败可记录提示并联系维护者 |
| 透明度滑块不可操作                   | 检查是否开启「实色背景回退」；原生不透明版始终禁用滑块                                                       |
| 窗口透视显示异常或文字难读           | 提高背景不透明度，开启「实色背景回退」；窗口本身异常时改用 `opaque` 版本                                     |
| 看不到某一年的官方补班               | 当前仅内置 2026 年。其他年份有未录入提示；不要把普通周末底色当作官方放假通知                                 |
| 导入被拒绝                           | 使用 Starry List 导出的有效 JSON，核对格式及版本，确认文件不超过 32 MB；只改扩展名不能变成有效备份           |
| 合并导入后出现重复任务               | 合并遇到重复 ID 会保留双方，不按标题去重；先导出当前数据，再决定删除重复任务或从备份完整恢复                 |
| 重装后清单为空                       | 检查是否换了 Windows 用户或卸载时删除了应用数据；用自己的 JSON 备份恢复，示例截图中的任务不会自动出现        |
| 关闭窗口后托盘没有图标               | V1.0 没有系统托盘；关闭即退出，需要从开始菜单重新启动                                                        |

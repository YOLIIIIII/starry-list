# 星轨日历 Starry List V1.0 用户手册

星轨日历是一款保存在电脑本地的日历待办工具。无需账号，日常使用无需联网。你可以用「统筹总览」安排不同日期，再用「专注编辑」写下具体步骤。

本文按 V1.0 实际界面、任务编辑器、设置及安装器配置编写。界面默认使用简体中文。安装器中的应用名称为 **Starry List**，应用窗口内显示「星轨日历」。

2026-10-28 更新：以下说明对应 SL-007 体验版，保留 UX3.2 的两顶部、三字号、三种材质与专注固定新增；更早安装包可能没有日程范围选择。

## 首次使用五分钟快速上手

1. 安装默认透明版，从 Windows 开始菜单搜索 **Starry List** 并打开。
2. 在「统筹总览」的月历中点击今天的日期数字。右侧「接下来七天」从这一天开始；窄窗口中它位于月历下方。
3. 点击今天日期行右侧的小加号，在出现的输入框填写标题，按 **Enter**。新增任务只需要标题，成功后输入框自动收起。
4. 点击任务标题，进入「专注编辑」阅读详情。点击「编辑」，在抽屉的「详细计划」写下步骤，选择「重要」或「非常重要」，再点击底部「保存并收起」。
5. 完成后点击任务左侧的空心圆。最后点右上角齿轮，向下找到「数据备份」，用「导出 JSON」保存第一份备份。

初次启动进入「统筹总览」；以后启动会记住上次的工作模式，日期从当天开始。任务与设置由两个模式共享，无需重复录入。

## 1. 安装、选择版本与启动

### 安装 Windows 版本

1. 获取项目提供的 Windows x64 `-setup.exe` 安装包。正式发布后，在仓库 GitHub 的 **Releases → 对应版本 → Assets** 中下载；尚未发布时，可使用维护者提供的本地构建产物。
2. 双击安装包，选择安装器语言，按提示选择安装位置和开始菜单快捷方式位置。安装器面向当前 Windows 用户安装。
3. 安装器完成页提供「创建桌面快捷方式」选项，按需要选择。
4. 打开 Windows 开始菜单，搜索 **Starry List**，点击应用快捷方式；也可以使用安装时创建的桌面快捷方式。

目标系统为 Windows 10/11 x64；目前实际验证环境为 Windows 11，其他设备的验证范围见 [验证记录](VALIDATION.md)。应用需要 Microsoft Edge WebView2 Runtime。安装包内置运行时引导程序，系统缺失运行时时，首次安装可能需要网络；日常管理任务不需要网络。

当前安装包未配置代码签名，Windows 可能显示「未知发布者」或 SmartScreen 提示。源码中的版权和安装包发布者显示现已统一为 `yoli`；现有旧安装包需要重新构建才会包含更新，见 [验证记录](VALIDATION.md)。该署名不是已验证的签名证书身份。请核对安装包来源及维护者提供的 SHA256。

### 安装 SL-007 体验版

默认透明 Windows x64 体验包为 `Starry-List_1.0.0_x64-sl007-preview-20261028-setup.exe`，校验文件 `SL007-PREVIEW-20261028-SHA256SUMS.txt`，保存在维护者本地 `artifacts/`。仍为 1.0.0、同一正式应用标识，不是正式 Release。旧 UX3.2 包保留；本轮不重建原生不透明包。

安装前在旧版导出 JSON 备份并正常退出，再按下文同版本覆盖流程操作，不必卸载或删除数据。实际构建、SHA256 和尚未验证的安装/升级范围见 [验证记录](VALIDATION.md)。

### UX3.2 历史体验版

新默认透明包为 `Starry-List_1.0.0_x64-ux3.2-preview-20261026-setup.exe`，回退包为 `Starry-List_1.0.0_x64-ux3.2-opaque-preview-20261026-setup.exe`；校验文件 `UX3.2-PREVIEW-20261026-SHA256SUMS.txt`。均位于维护者本地 `artifacts/`，不随源码提交，不是正式发布。沿用相同应用标识与 1.0.0，更新前导出备份、正常退出旧版，按下文升级说明操作；无需卸载或删除数据。

### UX3.1 历史体验包

本轮默认透明版文件名为 `Starry-List_1.0.0_x64-ux3.1-preview-20261023-setup.exe`，配套校验文件为 `UX3.1-PREVIEW-20261023-SHA256SUMS.txt`，均在维护者本地 `artifacts/` 目录，不随源码上传 GitHub。它仍使用 1.0.0 和相同应用标识，会更新同一个应用，不是并行安装的第二套软件；UX3.0.4 及更早体验包另外保留。

原生不透明回退包为 `Starry-List_1.0.0_x64-ux3.1-opaque-preview-20261023-setup.exe`，使用同一份校验文件；本轮验证范围见 [验证记录](VALIDATION.md)。通常先选默认透明版，不透明原生窗口不会产生桌面透视或模糊。

先在旧版设置中「导出 JSON」备份重要任务，再正常关闭旧版。运行新安装器，沿用原安装目录；如果检测到同版本，选择「添加/重新安装组件」继续覆盖，不要选择卸载。该选项已按实际生成的 NSIS 脚本核对，但本轮没有执行安装器验证。无需为了更新而手动卸载或删除数据目录。如果提示应用仍在运行，取消后正常退出旧版再重试。提示不明确时保留备份并取消，不要勾选「删除应用程序数据」来解决。安装后从开始菜单重新启动，检查任务和详情是否保留。

### 透明版和不透明回退版怎么选

| 版本                                | 适合的情况                                   | 背景设置                                           |
| ----------------------------------- | -------------------------------------------- | -------------------------------------------------- |
| 默认透明版：文件名不含 `opaque`     | 希望窗口融入桌面壁纸，优先选择此版           | 可调整背景不透明度；也可打开「实色背景回退」       |
| 原生不透明回退版：文件名含 `opaque` | 透明版出现渲染异常，或希望使用原生不透明窗口 | 窗口不会透视桌面，透明度滑块不可操作，并有明确说明 |

透明版显示异常时，先尝试「设置 → 实色背景回退」。如果窗口本身无法正常呈现，再使用原生不透明回退安装包。两版使用相同应用名称和数据目录；切换前先导出备份并退出应用。如需卸载，注意不要勾选删除应用数据。

## 2. 认识界面与统筹总览

窗口最上方左侧是星球图标和名称，中间的空白标题区可以拖动；Logo 和按钮不用于拖窗。右上角依次是图钉、齿轮、最小化和关闭按钮。「设置 → 顶部布局」提供经典顶部（默认）与紧凑顶部。经典为舒展双行，下方显示「统筹总览」「专注编辑」；紧凑将品牌、两个模式图标及窗口控制放在同一行，日历图标代表统筹总览，清单图标代表专注编辑。悬停可查看名称，也可用 Tab / Enter 操作。

顶部选择即时预览，重启后保留，与文字大小及外观独立。旧配置缺少字段时使用经典顶部；保存期间显示提示，失败会恢复已保存布局并提示错误，可重试。

宽窗口中，统筹总览左侧是月历，右侧日程标题可选择「接下来七天」或「本周」。窗口变窄后两块区域上下排列；更窄时，月历预览会减少文字，保留任务数量和重要任务标记。日程可以独立向下滚动，不需要把七天全部塞进一屏。

参考 [统筹总览截图](screenshots/overview.png) 和 [紧凑窗口截图](screenshots/compact.png)。截图使用示例任务，不代表你的数据库中预装了任务。

### 查看月历

- 月历从周一开始；月份标题右侧的左右箭头切换上个月、下个月，中间「今天」返回当天。
- **点击日期数字**选择日期。当天使用实心紫色日期标识，选中日期使用边框和底色，两者含义不同。
- 日期格中的任务预览优先显示未完成任务，再优先显示较重要的任务；预览数量随格子空间调整。`+N` 表示还有 N 项未显示的任务。
- 将鼠标放在任务预览上可查看完整标题；点击预览会直接进入该任务的专注编辑。
- 仅切换月份是在浏览月历，**不会改变选中日期或日程范围**。点击具体日期后，日程才按该日期和当前范围模式更新。

### 选择日程范围

右侧日程标题本身是「日程范围」下拉选择，可用 Tab 聚焦、方向键选择。下方始终显示实际首尾日期，跨年时两端年份均明确。每个日期分组显示日期、星期或「今天」，以及尚未完成的「N 项待办」；有任务时，分组下方还有「已完成数 / 总数」进度。

| 模式 | 显示的日期 | 前后箭头 |
| --- | --- | --- |
| 接下来七天（默认） | 从选中日期开始，连续七个自然日；例如选中 2027-01-01，显示 1 月 1 日至 7 日 | 选中日期向前/向后移动 7 天，沿用原行为 |
| 本周 | 包含选中日期的周一至周日；选中 2027-01-01 时显示 2026-12-28 至 2027-01-03 | 移动一整个自然周，保留选中日期的星期位置 |

“本周”按**选中日期所在周**计算；选中过去或未来日期时也如此，不强制回到今天所在周。点击分组日期会更新选中日期；连续七天以它为新起点，本周模式显示它所在的自然周。中间日历按钮返回今天；当前范围模式不变。

范围偏好即时预览并保存，重新启动后保留模式；选中日期仍按既有启动规则回到当天。旧设置/备份没有该字段时默认连续七天；保存中会有状态提示，设置保存失败会恢复已保存的范围并显示错误，可再次选择重试。范围切换只改变展示，不会移动或改写任何任务的日期。

**有未保存的标题时切换范围，会先按现有机制保存到原日期，成功后才切换。** 如果任务保存失败，原范围和草稿都会保留，不会因为日期退出当前列表而丢失。原日期不在新范围时，切回原范围即可查看，任务没有移动。若任务已经保存、随后仅范围偏好保存失败，已保存的任务仍在原日期，范围恢复旧值；不要重复新建。中文输入法组合期间请先完成选词，再切换范围。

空日期默认只有紧凑日期行和「0 项」，不显示输入占位符。每个日期右侧的小加号可打开该日期的新增输入栏；标题区域的「新增」按钮为当前选中日期打开输入栏。整段七天都没有任务时，只显示一次整体提示。

## 3. 在指定日期新增待办

**总览中新增：**先看清日期分组，点击日期行右侧加号，在出现的「添加一件小事…」中输入标题，按 **Enter**；也可点击旁边出现的「添加」。成功后输入框收起并显示真实任务。**通过输入框 Enter 保存成功后，焦点会返回刚才那个日期的加号，再按一次 Enter 就能继续添加同一天的下一条。**第一次 Enter 只保存；保存期间若点击、导航、按其他键或切换软件，会尊重新操作，不迟到地抢回焦点。点「添加」或失焦自动保存不执行此焦点返回。请以真实任务和成功通知为准。任务自动归属该分组日期，而不是一律归到今天。

**专注中新增：**确认主区域顶部日期，在专注面板底部直接输入。新增区固定在任务列表外；展开长详情或滚动清单时，它仍留在底部，不用先滚到最后。Enter 成功后清空输入，可继续输入下一条；任务列表单独滚动，长详情随列表完整读取。详情顶部的编辑、收起及任务删除按钮可随列表滚回访问；编辑抽屉仍独立滚动并固定保存栏。

新增时无需选择分类、优先级或填写详情。保存成功后输入栏清空，任务出现在清单和月历中。若添加失败，输入文字会保留，并显示错误，请处理后重试。

七天日程同一时间只展开一个新增区。输入框为空或只有空白时，点击外部、再次点该日期加号、按 **Esc** 或点输入旁的关闭按钮都会收起；直接点其他日期加号会切换到那个日期，不创建空任务。

已经输入非空标题后，点击输入区域外的应用位置，或切换到其他 Windows 软件，会尝试添加到输入开始时的原日期。只有 SQLite 成功后才清空并收起；失败保留文字和日期，返回应用可看到错误，点击「重试添加」（可访问名称仍为「添加到 日期」）重试。当你主动选择其他日期、七天范围、切换模式或点击另一天的加号，应用会先将标题添加到原输入栏所属日期，写入成功后直接切换，并显示轻量成功提示；不再要求三选一。失败时保留原日期和草稿，显示错误且不切换，处理后可重试。保存期间不能重复提交。

如果确实不想添加，按 Esc、点输入旁关闭按钮或再次点当前日期加号，会出现「要放弃这条尚未添加的任务吗？」：选择「继续填写」保留，选择「放弃草稿」才丢弃。空白直接收起，不创建空任务。专注模式的新增栏常驻，取消后清空；总览的新增栏会收起。参考 [取消新增确认](screenshots/quick-add.png)。

中文输入法组合阶段不提交；若期间失焦，等待选词结束后的最终文字再尝试保存。若系统没有发出 compositionend，会保留草稿等待结束，不能声称已保存。主动导航请先完成选词。新增成功的「已添加任务」通知可点「撤销」真正移除误添加的任务；保存后 Esc 不再取消该任务。通知约 5 秒后结束，悬停/键盘焦点会暂停，可手动关闭。

新增输入、占位符和真实任务标题共用字号：小 13px、标准 14px、大 16px；在「设置 → 文字大小」选择。月历窄格预览仍保持紧凑，任务完整内容可在详情中读取。未添加的文字仍是草稿，强制结束进程无法保证恢复。**这与已有任务编辑抽屉不同**：抽屉取消/关闭/Esc 仍提供「继续编辑 / 放弃修改 / 保存并收起」；没有改动时直接关闭。

### 总览中快速修改标题

七天日程每条真实任务行右侧有铅笔图标「快速修改标题」，可访问名称为「快速修改 任务标题」。点击后在原行选中标题，输入新文字，按 Enter 或点击行外保存；Esc 或旁边「取消修改标题」恢复原标题。无变化不写库，空白不能保存。一次只编辑一条，失败会保留输入并阻止日期/模式切换及正常关闭，请点保存图标重试或按 Esc 取消。此入口只改标题；日期、详情、优先级、分类和简称仍从「··· → 编辑任务」进入抽屉。正常点击任务标题仍进入专注只读详情。

## 4. 完成、取消完成与进度

在七天日程或专注清单中，点击任务左侧的**空心圆**即可标记完成。完成后显示勾号，标题变浅并带删除线，任务排列到未完成任务之后。

再次点击勾号可以取消完成。星星或王冠的优先级仍保留，不会因为完成而被清除。两个视图的状态与任务数量会同步。

七天分组中的「N 项待办」只统计未完成任务；进度的分母包含全部任务。专注模式「当日清单」旁的数字也是当天全部任务数。

## 5. 专注编辑、详情和保存

点击顶部「专注编辑」进入当前选中日期的每日清单；也可以从总览直接点击任务标题或月历任务预览。

顶部日期右侧有前一天、后一天箭头及「今天」按钮。下方七天日期条以当前选中日期为中心，显示前三天、当天和后三天；点击某一天切换清单，日期下的小圆点表示这一天有任务。

任务默认是紧凑的一行。点击**任务标题**，先展开只读详情，展示完整标题、日期、重要程度、可选分类和详细计划，不会直接出现输入表单。长计划保留换行，在有高度上限的区域内滚动阅读；没有计划时保持紧凑。再次点击标题或收起按钮即可收起阅读卡片。

点击只读详情右上方的「编辑」，才会打开独立编辑抽屉。宽窗口中抽屉位于右侧，宽约 520px；窄窗口中占满可用宽度。它仍在同一个应用窗口内。抽屉的标题和底部操作固定，中间表单可以独立滚动。

参考 [专注编辑截图](screenshots/focus.png)。

### 撰写长文本

在编辑抽屉的「详细计划」多行文本框中写中文段落、换行、编号或列表。例如：

```text
调研范围：
1. 产品 A 的功能设计
2. 产品 B 的使用体验

下一步：
整理对比表，周五完成初稿。
```

这是纯文本编辑器，编号和列表作为文字保存，没有富文本工具栏。在文本框内按 Enter 是换行。文本框初始高度约 156px，随文字增高，最高约 340px；更多内容在文本框内滚动。其他字段可在表单中滚动查看，底部保存按钮始终可见。参考 [编辑抽屉](screenshots/editor.png) 与 [窄窗口编辑](screenshots/editor-compact.png)。

### 保存与取消编辑

- 点击抽屉底部「保存并收起」，或在编辑框内按 **Ctrl + Enter**。应用先校验并等待写入成功，再关闭抽屉、收起阅读卡片，回到紧凑清单并提示「修改已保存」。重新点击标题即可阅读已保存内容。
- 修改后显示「未保存 · 切换时自动保存」，此时仍是草稿。原有任务、日期、模式切换及正常退出前的保存保护继续生效；保存失败会阻止切换。抽屉打开时，请先保存或取消，再操作底层列表。
- 保存失败会保留抽屉和输入，并提示「保存失败，你的输入仍保留在这里。」；解决问题后可重试，不会把失败当作成功。
- 点击「取消」、右上角关闭按钮，或按 **Esc** 退出编辑。没有修改时直接关闭；有未保存修改时，出现「保留这次修改？」确认框，可选择「继续编辑」「放弃修改」或「保存并收起」。只有明确选择「放弃修改」才会丢弃本次草稿，不会覆盖原任务。

重要长文本建议主动点「保存并收起」并确认成功提示。强制结束进程、断电时，尚未保存的草稿不能保证保留。窗口底部「本地保存 · 安心离线」不是每个编辑框都已提交的提示，请同时查看抽屉的保存状态。

## 6. 重要程度、分类与日历简称

这些入口都在**点击「编辑」后打开的抽屉中**，不在快速新增栏或只读详情中。选择后点击「保存并收起」生效。

### 星星与王冠

找到「重要程度」，选择一个胶囊按钮后保存：

| 按钮     | 清单与月历中的标识 |
| -------- | ------------------ |
| 普通     | 没有特殊图标       |
| 重要     | 黄色星星           |
| 非常重要 | 金黄色王冠         |

列表里的星星或王冠是状态标识；修改时请点击编辑抽屉内的选项。重要程度会影响月历预览的优先顺序，日清单仍按手动顺序及完成状态排列。

### 分类

「分类」位于重要程度下方。可选择「工作」「生活」「调研」「开发」「会议」「学习」，每条任务最多一个。选择「不选择」移除分类，然后保存。

分类可选，不选不会影响新增或完成。分类显示在七天日程和专注清单中；V1.0 没有分类增删改管理界面。

### 日历简称

分类下方有折叠的「更多选项」。点击展开，在「日历简称」中填写简短名称，例如将「完成 AI 调研报告」设为「AI 调研」，然后保存。

简称只用于月历预览，不改变完整标题或详情。不填写简称时，月历显示原标题，并用省略号适应空间；鼠标悬停仍能看到完整标题。清空简称并保存即可恢复原标题预览。

## 7. 改变任务日期、排序与删除

### 改变日期

展开任务的只读详情，点击「编辑」，在「任务日期」中选择新日期，再「保存并收起」。任务会移动到新日期，可能从当前清单中消失。到月历选择新日期，或在专注模式切换到新日期，即可继续查看。

### 手动排序

排序入口只在**专注编辑的任务行最右侧**，是小的上箭头和下箭头。每次点击将任务上移或下移一位，顺序即时保存，无需再打开编辑抽屉保存。

只能在同一天、同完成状态的任务之间排序：未完成任务始终在已完成任务之前，边界处的箭头不可点击。月历预览另有未完成、优先级优先的规则，所以月历顺序可能与每日清单不同。

### 删除与撤销

**统筹总览**：任务行右侧保留「···」菜单，可选「编辑任务」或「删除任务」。编辑会进入正确日期的专注模式及原抽屉。参考 [总览任务菜单](screenshots/task-menu.png)。

**专注编辑**：任务行右侧是常驻的低调垃圾桶图标，悬停说明及可访问名称为「删除任务」；点击后仍需确认，不会立即删除。上下排序箭头保留在旁边。编辑请点击任务标题展开只读详情，再点「编辑」；已完成任务也可删除。

选择「删除任务」后，在确认框中核对标题，点「保留」取消，点「删除任务」确认。写入成功后才移除任务；失败时任务和确认框保留，并显示错误，可处理后重试。删除与撤销会同步日历预览、清单和统计，不会删除同一天的其他任务。

原入口仍保留：从只读详情点击「编辑」，在抽屉中部表单向下滚动，找到「更多选项」下面的「删除任务」。两种入口使用相同确认与撤销流程。

专注删除图标可用 Tab 聚焦、Enter / Space 打开确认。总览菜单键盘操作：Tab 聚焦「任务操作」按钮，Enter / Space 打开；上下箭头或 Home / End 选择菜单项，Enter 执行；Esc 关闭并返回按钮，Tab 离开菜单。菜单跟随滚动重新定位，靠近窗口下边缘时向上展开。

窗口顶部居中的紧凑通知区显示「任务已删除」与任务标题，点「撤销」真正恢复原任务全部内容。每条通知约 5 秒后自动消失，鼠标悬停或键盘焦点停留时暂停，离开后继续剩余时间；也可手动关闭。连续删除会分别保留有效的撤销通知，不覆盖前一条，可点击右侧数量按钮逐条查看，也可用 Tab 访问各条撤销。撤销失败时保留重试。超时/关闭只结束撤销入口，不再次修改数据库；编辑抽屉、删除确认、设置或导入弹窗打开时，通知暂时隐藏并暂停计时，关闭后恢复。通知不推动主布局，只有通知本体和数量按钮接收鼠标点击。多个有效通知各自计时，未查看也会到时结束；如需保留撤销机会，可将鼠标或键盘焦点停在相应通知上。这不是长期回收站，退出后也不保留，重要任务仍应备份。

## 8. 节假日、补班与个人标记

月历内置 2026 年中国大陆官方安排，无需联网获取：

| 标记 | 含义                                   |
| ---- | -------------------------------------- |
| 休   | 官方假期，例如 2026 年 10 月 1–7 日    |
| 班   | 官方调休上班，例如 2026 年 10 月 10 日 |
| 歇   | 你设置的个人休息                       |
| 加   | 你设置的个人加班                       |

官方假期和补班会优先于普通周末底色；例如补班的星期六不会被当成普通休息周末。鼠标悬停「休」可查看假期名称，悬停「班」可查看官方补班说明。

在右上角齿轮「设置」中，可以切换「官方节假日」和「周末底色」。未录入官方安排的年份会显示提示，不会猜测调休日期。

### 标记个人休息或加班

进入「统筹总览」，在月历中选择日期。**月历下方**有「某月某日 · 个人标记」一行，通过右侧下拉框选择「个人休息」或「个人加班」；选择「无」清除个人标记。选择后即时保存。

个人标记不会改写官方安排；同一天可以同时显示官方「休」和个人「加」。V1.0 界面没有个人标记备注编辑入口。

## 9. 拖动、缩放、最小化与置顶

- **拖动：**按住顶部左侧品牌名称区域或中间空白标题区拖动。任务行、编辑框和右上角按钮不是拖动区域。
- **缩放：**拖动窗口边缘或角落，也可以按住右下角的小点阵拖动。最小窗口为约 380 × 480 逻辑像素；较小窗口会调整布局。
- **最小化：**点击右上角减号，窗口进入 Windows 任务栏；点击任务栏图标恢复。
- **置顶：**点击右上角图钉，或打开齿轮「设置」切换「始终置顶」。再次操作取消；默认关闭，选择会保存。
- **恢复：**正常退出后再启动，会恢复窗口尺寸、位置和工作模式。显示器变更时，应用会尝试把窗口调整回可见区域；不同多显示器环境仍需实际验证。

V1.0 没有系统托盘功能。右上角关闭按钮是退出应用，不是隐藏到托盘。

## 10. 背景透明度与其他设置

点击右上角**齿轮**打开「让星轨更适合你」。设置较长时在面板内向下滚动，底部有数据备份和版本说明；没有独立的「关于」菜单按钮。参考 [设置截图](screenshots/settings.png)。

默认透明版的「背景不透明度」滑块范围为 **40%–100%**，初始约 **85%**。数值越低，桌面越容易透过外壳、边缘和留白；100% 表示完全不透明。UX3.0 的月历、七天日程和专注清单使用稳定的浅色阅读衬底，低透明度也不会让整个内容区随外壳一起变淡，这是阅读保护。拖动时实时预览，松开或使用键盘调整后保存；文字、图标及输入区域保持清晰，不随整个窗口一起变淡。

设置顶部新增「外观模式」，点选即保存，下次启动保留：

- **阅读优先**：默认，奶油阅读衬底最稳定，适合长时间阅读。
- **轻玻璃**：更通透的清浅紫色材质；由内容面保护文字，不再给日期数字和每行任务贴常驻底块。
- **梦幻毛玻璃**：柔紫浅金与更明显的背景氛围。UX3.0.3 在支持的 Windows 11 上采用稳定的原生背景合成，切换其他软件时不再使用系统 Acrylic 的失焦实色样式。Windows 10、原生不透明窗口、系统禁用透明/高对比或初始化失败会降级；电源、远程桌面及 GPU 策略仍可能使模糊不可用，不能保证所有设备与激活态完全相同。

外观模式选择材质，透明度滑块调整通透程度，二者独立。100% 关闭桌面模糊和透视，三种模式仍保留各自配色；实色回退同样关闭模糊。出现性能或观感问题时，可直接改回阅读优先。旧设置或旧 JSON 备份没有外观选项时，默认采用阅读优先，不改变任务。

UX3.0.4 将三种外观的七天/专注任务排列统一为阅读优先的密度；切换材质不再改变任务和按钮位置，玻璃继续没有常驻小底贴。月历会按实际剩余空间调整预览；数字能完整显示才出现，过矮时改为完整圆点，点击对应日期仍能在七天日程查看完整数量和任务。日期按钮的可访问描述也保留总数。极矮窗口中月历面板可向下滚动，避免日期或角标在格子内部被裁掉。面板滚动边界上的部分行可滚动移入，与格子内部数字裁切不同。详见 [UX3.0.4 布局对比](UX3_0_4_VISUAL_REVIEW.md)。

顶栏共用连续圆角背景，标准档任务标题仍为 14px。UX3.0.3 保留纯文字星期标题，进一步去掉玻璃日期数字、七天日期行及任务行的常驻底贴；历史预览间距 4px、任务组间距 3px（UX3.0.4 已采用共同布局规则），快速新增与清单保持分离、左侧留白更舒适（容器 10px / 12px，文字另有 6px 内边距）。编辑抽屉输入与详细计划 14px、标签/操作 12px、辅助说明 11px；这些是 UX3.0.3 的历史标准值；UX3.1 已将这些角色接入小 / 标准 / 大三档，标准值保持。风格及前后对比见 [UX3.0.3 对比](UX3_0_3_VISUAL_REVIEW.md)，旧版记录保留。Enter 连续新增与失焦保存保持；顶部通知中的关闭按钮位于最右，撤销在它之前。恢复/保存成功与撤销通知约 5 秒消失，鼠标悬停、键盘焦点或抽屉/弹窗打开时暂停；通知消失不会更改已保存的数据。

梦幻毛玻璃不会在每次切换主视图时重新叠加材质。UX3.0.3 延续异步去重和失败清理，并替换会随失焦转实色的系统 Acrylic 预设；仍需在你的系统、透明度及电源设置下最终体验。如遇异常，可先切到「阅读优先」或开启「实色背景回退」，任务不会因此改变；反馈时说明 Windows 版本、外观和不透明度、出现前的操作即可，无需提供私人壁纸或任务截图。

开启「实色背景回退」后，背景完全不透明，滑块不可操作；关闭它可恢复透明度调整。原生不透明版的滑块始终不可操作，即使关闭此开关也不能透视桌面。

「柔和动画」「官方节假日」「周末底色」「始终置顶」等开关即时保存。系统要求减少动画时，界面也会减少动画。

## 11. 导出与导入 JSON 备份

### 导出

1. 点击右上角齿轮。打开设置前，应用会先尝试保存正在编辑的任务详情。
2. 在面板内向下找到「数据备份」，点击「导出 JSON」。
3. 在系统保存对话框选择位置，建议保留带日期的文件名，例如 `Starry-List-2026-10-14.json`。
4. 看到「备份已导出」后确认文件已保存。取消文件对话框不会导出。

备份包含任务、详情、分类、个人日期标记和应用设置，不包含窗口位置与尺寸，也不包含只读官方节假日数据。JSON 未加密，请妥善保管；应用没有自动云备份。

### 默认合并导入

1. 在「设置 → 数据备份」点击「导入 JSON」，选择 Starry List 导出的 JSON 文件。
2. 文件通过校验后出现「确认导入备份」，显示任务、分类和个人标记数量。
3. 保持「覆盖现有全部数据与设置」**未勾选**，点击「合并导入」。
4. 看到「备份已完整导入」后查看结果；不想导入时点击「取消」。

合并会保留现有任务和设置；同一天的个人标记保留现有值。相同任务 ID 会生成新 ID，**不会按相同标题去重**，因此重复导入同一备份可能产生重复任务。分类 ID 冲突且名称或颜色不同，会作为另一个分类保留。已有任务不会被备份悄悄覆盖。

### 完整覆盖恢复

如果希望整库恢复为备份中的内容，请先导出当前数据。在确认框勾选「覆盖现有全部数据与设置」，按提示输入 **覆盖**，然后点击「确认覆盖」。

覆盖会替换当前任务、分类、个人日期标记和设置；它不是简单追加。窗口几何状态不随 JSON 恢复。导入在事务中完成，失败时不会留下部分写入。错误版本、无效结构或超过 32 MB 的文件会被拒绝并显示错误。

## 12. 本地数据保存在哪里

正常 Windows 安装版的 SQLite 数据库位于：

```text
%APPDATA%\app.starrylist.desktop\starry-list.db
```

例如：`C:\Users\你的用户名\AppData\Roaming\app.starrylist.desktop\starry-list.db`。打开 Windows 文件资源管理器，在地址栏输入 `%APPDATA%\app.starrylist.desktop` 并回车即可进入。

任务、分类、个人标记和应用设置都在数据库内。窗口状态另由窗口状态插件保存；不是 JSON 导出内容。透明版和不透明版共用同一数据目录。

应用运行期间可能还有 `starry-list.db-wal` 和 `starry-list.db-shm` 文件，它们属于 SQLite 正常工作文件。不要在应用运行时删除它们，也不要只复制主数据库作为完整备份。一般用户优先使用应用内的「导出 JSON」；需要手动复制数据库时，先正常退出应用，再复制完整数据目录。

数据没有上传到服务器，也没有本地加密。不同 Windows 用户通常拥有各自的数据目录。重新安装程序不等于已经恢复数据，重要内容请定期导出。

## 13. 退出、卸载与重新安装

### 退出

点击右上角 **×** 关闭应用。正常关闭前会尝试保存非空快速新增、行内标题修改和编辑抽屉中的修改，并等待本地写入完成；失败会保留输入、显示错误并阻止退出。中文输入法正在选词时，请先结束选词再关闭。强制结束进程不属于正常保存流程。

最小化只把窗口放到任务栏，不会退出应用，也不会隐藏到系统托盘。

### 卸载

1. 先在应用内导出 JSON 备份，再正常退出。
2. 在 Windows 设置的已安装应用列表中找到 **Starry List**，选择卸载；Windows 10 中通常位于「应用和功能」。
3. NSIS 卸载确认页有 **「删除应用程序数据」** 复选框。希望保留本地任务时，不要勾选；勾选会删除应用数据目录，包括数据库和设置。

如果需要彻底清理，也应先确认备份可用再选择删除数据。本项目尚未在全新设备上完成安装、升级、卸载回归，说明依据当前生成的 NSIS 安装器流程。

### 重新安装

重新运行可信来源的安装包，之后从开始菜单打开。数据目录仍存在时，应用会读取其中的任务；目录已经被删除时，需要用先前的 JSON 备份导入恢复。若要完整恢复到备份状态，使用明确确认后的覆盖导入；如果只是追加任务，使用合并导入。

| 找不到星星、王冠、分类或简称入口     | 点击任务标题查看详情，再点「编辑」；简称在抽屉的「更多选项」内；日历上的星星本身不是设置按钮                 |
| 找不到上下排序箭头                   | 切换「专注编辑」，看任务行最右侧；处于同完成状态分组边界时箭头禁用                                           |
| 保存改日期后任务不见了               | 到新日期查看；还要检查是否被标记完成并排到了清单后面                                                         |
| 长文本还显示未保存                   | 点击「保存并收起」或 Ctrl + Enter，查看错误和保存状态；不要直接强制结束程序                                  |
| 提示保存失败或启动时无法读取数据库   | 检查磁盘空间和数据目录写入权限。保留输入与原数据；不要为了消除提示删除数据库。启动失败可记录提示并联系维护者 |
| 透明度滑块不可操作                   | 检查是否开启「实色背景回退」；原生不透明版始终禁用滑块                                                       |
| 窗口透视显示异常或文字难读           | 提高背景不透明度，开启「实色背景回退」；窗口本身异常时改用 `opaque` 版本                                     |
| 看不到某一年的官方补班               | 当前仅内置 2026 年。其他年份有未录入提示；不要把普通周末底色当作官方放假通知                                 |
| 导入被拒绝                           | 使用 Starry List 导出的有效 JSON，核对格式及版本，确认文件不超过 32 MB；只改扩展名不能变成有效备份           |
| 合并导入后出现重复任务               | 合并遇到重复 ID 会保留双方，不按标题去重；先导出当前数据，再决定删除重复任务或从备份完整恢复                 |
| 重装后清单为空                       | 检查是否换了 Windows 用户或卸载时删除了应用数据；用自己的 JSON 备份恢复，示例截图中的任务不会自动出现        |
| 关闭窗口后托盘没有图标               | V1.0 没有系统托盘；关闭即退出，需要从开始菜单重新启动                                                        |

如果问题仍存在，请记录 Windows 版本、问题操作步骤和完整错误文字，按 [贡献与反馈说明](../CONTRIBUTING.md)反馈。请不要公开上传个人数据库或含隐私的 JSON 备份。

## UX3.1 文字大小与五分钟体验

齿轮设置内提供「文字大小」：小 / 标准（默认）/ 大。选择后立即预览，同时保存；保存期间显示「正在保存文字大小…」。保存失败会显示错误并回到上次保存的字号，可以重试。成功后关闭并重新打开应用，字号仍保留；它与外观、透明度分别记忆。旧设置和旧 JSON 备份没有该项时使用标准，不影响已有任务。

标准档保留现有 14px 任务文字；小档适合多看一些内容，大档更舒适。日期、分类、说明和按钮按各自层级调整，月历预览采用紧凑字号及省略；点任务读取完整标题和详细计划。编辑抽屉内容可以独立滚动，保存/取消留在底部。

UX3.1 历史顶部为收紧两行；UX3.2 已改为经典（默认）/ 紧凑单行可选，两种均保留英文品牌，矮屏可隐藏装饰句。三种外观的同档布局相同，梦幻毛玻璃仍受原有系统兼容边界约束。

五分钟体验清单：

1. **第 1 分钟**：导出 JSON 备份，正常退出旧版后安装 UX3.1；打开确认原任务仍在。若旧版仍运行，取消安装后自行退出，不卸载或删除应用数据。
2. **第 2 分钟**：设置里依次选小 / 标准 / 大，比较任务与新增输入；保留舒服的一档，关闭重开确认记住。
3. **第 3 分钟**：在三个外观间切换，比较日期和任务位置；梦幻状态切其他软件再回来，观察是否出现明显实色跳变。
4. **第 4 分钟**：新增一条长中文任务，Enter 保存后再按 Enter 连续新增；再输入一条并切到其他软件，返回确认自动保存。打开详情、编辑长计划，滚到下方检查保存/取消始终可见。
5. **第 5 分钟**：试窄窗口与矮窗口、拖动顶部空白和边缘缩放；完成一条测试任务、删除并撤销。记录字号偏好，以及任何裁切、重叠或保存异常。

本轮是体验包，SL-004 / SL-005 保持待验收；安装包构建、用户体验与正式发布分别记录，当前没有正式 Release。对比与具体验证范围见 [UX3.1 视觉记录](UX3_1_VISUAL_REVIEW.md)。

## UX3.2 五分钟体验

1. 更新前导出 JSON 备份，正常退出旧版后安装 UX3.2；确认原有任务仍在。
2. 打开设置，比较「经典顶部（默认）」与「紧凑顶部」。紧凑的日历/清单图标分别切换总览/专注，悬停查看提示。
3. 分别选小/标准/大和三种外观，观察品牌、窗口控制及导航是否自然；关闭再打开应用，确认顶部、字号和外观都记住。
4. 在专注展开一条长计划，滚动到中间与末尾，再将窗口缩矮/缩窄；底部「添加一件小事…」应始终可见。连续输入两条、每条按 Enter，检查日期、清空与成功提示；再输入一条切到其他软件，返回检查自动保存。
5. 试一次取消草稿（选择继续填写）、编辑/收起详情及删除/撤销；梦幻模式切到其他软件再返回，观察材质是否稳定。反馈时说明顶部、字号、外观和窗口大小即可，无需提交私人任务或壁纸。

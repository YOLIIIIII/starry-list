# UX3.0.4：共用清单布局与矮窗口月历

本轮沿用 [SL-003-C](PRODUCT_BACKLOG.md#sl-003)，作为玻璃视觉阶段的小型收尾。用户已认可 UX3.0.3 的轻玻璃/梦幻整体材质，三种模式、透明度、失焦修复、14px 与编辑抽屉均保留。实现后 In Review，待安装确认，未正式发布。实现提交 [`4963483`](https://github.com/YOLIIIIII/starry-list/commit/4963483c82f9f712e3cf70f6c9a82707b3cca071)。

## 清单位置为什么不同

UX3.0.3 的玻璃作用域额外设置任务上/下外间距 3px、左右内边距 5px、圆角 10px；专注新增区还有额外 3px 顶部内边距。玻璃专注任务取消了底边框，阅读优先保留 1px；今日日期胶囊的玻璃 padding 又与阅读优先不同。这些规则不仅改变材质，也改变行高、换行宽度、日期分组位置及展开卡片的外边距。

本轮移除材质布局覆盖，采用阅读优先共同规则：

| 区域       | 三种外观共用的值                                                             |
| ---------- | ---------------------------------------------------------------------------- |
| 七天任务   | 外间距 0；最小行高 33px，内边距 5px 0；任务内部 gap 7px                      |
| 专注任务   | 外间距 0；最小行高 43px，内边距 9px 6px；窄屏沿用 8px 2px                    |
| 专注分隔   | 始终保留 1px 占位，玻璃仅改成透明颜色                                        |
| 七天日期组 | 上/下内边距 13px / 11px，组底线 1px；日期标题下方 6px                        |
| 展开阅读   | 沿用共同外边距，上 5px、下 10px，关闭后恢复紧凑行                            |
| 快速新增   | 专注上下 margin 9px，无玻璃额外 3px；容器 10px / 12px、输入 6px 左内边距保留 |

在 980px 的合成样例中，普通七天单行实际为 35px，双行 56.8px；专注单行 44px。最小行高不是固定行高，标题换行、操作按钮和阅读详情可增加高度。三模式测量任务、标题、完成圈、分类、排序/删除、日期组和新增区的位置，而不是只比较一个 CSS 变量。玻璃仍无常驻任务底板，阅读优先底色未复制到玻璃；颜色与模糊保持各自语义。

## 数量为什么只露半截

旧 ResizeObserver 仅用第一格外部宽高和固定 54 / 86px 阈值决定预览，未扣除内边距、边框、日期栏或角标换行高度。markers-only 数量按钮又没有可收缩高度与整行显示保护，日期格 overflow:hidden 会截掉流到下方的数字；极矮时日期本身也可能被裁。

新方案测量实际日期栏和内容空间，按统一预览 token（普通 17px、高宽窗口 20px，间距 3px / 5px、顶部留白 5px）选择密度，留 1px 安全空间；同几何尺寸内只降级，真正尺寸或任务数据变化再评估，避免 +N 换行引起反复切换。观察器按帧合并并在卸载时清理。

数量按钮在 flex 剩余空间内可收缩到 3px，最大 12px；容器查询只有在完整 12px 行可用时显示数字，否则只显示完整圆点。可访问名称和日期按钮描述仍包含真实任务总数。旧 WebView 不支持容器查询时也保留圆点/可访问总数，不显示半截数字。

日期/角标的有限最小行高由实际日期栏 + padding + border + 4px 圆点空间决定；普通样例为 41px，同时有官方假期和个人标记时实测可为 48px。数量不会让最小高度继续增大。极矮时月历面板可滚动，避免格子内部裁切；面板滚动边界上的行可滚动移入，不保证任何滚动位置都恰好停在整行边界。没有隐藏官方/个人标记或改写任务数量。

## 用户验收

1. 在同一天放入短标题、长中文、已完成及带分类的任务，依次切换三种外观；检查总览和专注的行、按钮及日期组位置一致。
2. 展开/关闭只读详情，再打开新增区；检查留白自然，玻璃没有恢复白色小任务底板。
3. 试 980 × 480 / 620 / 680，以及 380px 窄窗口；查看四/五/六周月份。数字完整显示或改为圆点，可点击日期查看真实数量；过矮时可滚动月历。
4. 连续 Enter 新增、失焦保存、快速修改、删除撤销和抽屉草稿仍照常；梦幻切其他软件后不应回归明显实色跳变。
